# Scene canons (owner, Oct 2026)

Who belongs to a scene, built from what critics, historians and best-of lists say, not from what Fandome already
has. Each `<scene>.csv`: artist, country, tier (1 essential, 2 important, 3 notable), key albums with years,
whether the artist is in the catalogue, the albums still missing, and the sources. `<scene>.md` lists the
sources (outlet, author, year, URL) and the scope decisions. Descriptor waves pick from these lists, tier 1 first,
and add the artists the catalogue lacks.
