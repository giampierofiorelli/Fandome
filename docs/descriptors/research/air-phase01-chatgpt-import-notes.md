## Import rules

- Append exactly four rows to `docs/descriptors/air.csv` with the given header; never replace other artist rows or existing Air rows if another batch has arrived since this audit. Recheck catalogue and descriptors immediately before merge, dedupe by IDs.
- Add *Premiers Symptômes* (1997) to Air's album tuples in `src/data/catalog.ts` before Moon Safari. This historically important **five-track original EP** is not a full-length studio album. The 1999 seven-track edition has **two additional tracks** absent from the original; do not accidentally evaluate 1999-only material. The original EP contains previously released singles; no duplication at album-ID level.
- Existing three catalogue IDs generated by the existing `slug()` function MUST be preserved. The `10 000 Hz Legend` title is already in the catalogue; preserve spaces in display name and `air-10000hzlegend` ID.
- Add **four taxonomy tokens** if still absent: `ambientpop`, `lounge`, `spaceagepop`, `spacepop`. Consult genre-evidence scopes: don't present minor elements as dominant. Maintain genreParents consistency; candidate mappings and caveats in evidence-notes. The validator's explicit GENRES Set must also be updated. All other tokens in this ZIP existed in the inspected `scenes.ts` union.
- Producer precision: `Premiers Symptômes` credits Étienne de Crécy on two tracks only. `Moon Safari` producer duo only, not string arranger David Whitaker or mixer Stéphane Briat. `The Virgin Suicides` producer duo, not lead vocalist Thomas Mars (Gordon Tracks). On `10 000 Hz Legend`, Tony Hoffer **additional producer only on Caramel Prisoner**, despite mixing more tracks.
- `Premiers Symptômes` is almost instrumental; its language is deliberately left empty because the one processed croon is not independently resolved. Never infer singing language from a French title. On *10 000 Hz Legend*, Japanese is confined to a guest-vocal track.
- Fandome 0–5 scales are album-wide **editorial judgments justified by album-specific evidence**. Empty is allowed; don't force unsupported certainty. Influences are rigorously narrower than sonic resemblance. The generic AllMusic Alternative/Indie Rock genre metadata is low-strength and flagged by scope.
- Run `npx vite-node scripts/validate-descriptors.ts`, tests and app build **after** catalogue and any genre extensions. Do not mark reviewed without a second qualified check.
